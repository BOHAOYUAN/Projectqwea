# 🧋 Sunny Tea House · AI 商业数据分析与运营中台 (BI Dashboard)

一套专为加州圣何塞门店打造的 **商业级顾客评价分析与 AI 决策支持系统**。

---

## 🌟 核心功能特性

1. **📊 实时全渠道动态大屏**：
   - 自动统计并监控 Google Maps & 小红书全渠道评价；
   - 交互式评分走势图、消费感受标签分布占比（饼图/环形图）、平台星级对比柱状图；
   - 核心运营指标（平均星级 4.8★、好评率 96.7%、AI 自动化处理率 100%）。

2. **🧠 AI 商业智能诊断 (Groq LPU 驱动)**：
   - 深度扫描顾客中英文语料，提炼**门店前 3 大核心竞争壁垒**；
   - 智能识别高峰期排队、甜度波动等**服务痛点与潜在风险**；
   - 输出面向店长/老板的**下周可落地行动清单（Actionable Insights）**。

3. **⚡ 批量处理流水线与报表导出**：
   - 支持上传自定义 Excel / CSV 评论数据；
   - 毫秒级批量生成 **20 字核心中文摘要** 与 **50 字老板亲切回复草稿**；
   - 一键导出结构化分析报告为 Excel（`.xlsx`）文件。

---

## 🚀 快速启动指南

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 一键启动看板
```bash
streamlit run app.py
```

浏览器会自动弹出访问 `http://localhost:8501`，即刻体验完整的商业智能中台！
